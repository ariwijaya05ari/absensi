# Absensi Pengajian — Frontend

Frontend statis (HTML/CSS/JS murni) untuk aplikasi Absensi Pengajian. Backend: Google Apps Script (`Kode.gs`, disajikan terpisah).

1. Isi `js/config.js` dengan URL Web App Apps Script (berakhiran `/exec`).
2. Deploy folder ini ke GitHub Pages — `index.html` harus di root repository.

Panduan lengkap: `PANDUAN-INSTALASI.md`.
